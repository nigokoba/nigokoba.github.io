kobatomoについて

HTMLとCSSで個人サイトを制作しています。写真、散歩、ガジェットが好きで、気になったことを調べたり、日記として記録したりしています。

このサイトでは、制作したものと日々の記録を紹介しています。

技術経験

このサイトの制作で使っている技術を紹介します。

HTML
見出し、ナビゲーション、記事、写真とキャプションを使った複数ページの構成。
CSS
共通スタイル、Gridによる写真一覧、Flexboxによるメニュー、メディアクエリによるスマートフォン表示の調整。
GitHub Pages
リポジトリのHTML・CSSを使った静的サイトの公開。
